ENCRYPTION ARCHITECTURE
HOW THE SECURITY WORKS
🔑
User Password → PBKDF2 → DEK: Each user's password derives a unique Data Encryption Key via 100,000 rounds of PBKDF2-SHA256. Brute-force resistant.
