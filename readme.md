\## Setup Instructions



1\. Upload all files to your GitHub repository.

2\. Enable \*\*GitHub Pages\*\* in repo settings.

3\. Open the site.

4\. Create an account or sign in.



\*\*Note:\*\* Firebase config is placeholder — update in `js/data.js` if you want real backend persistence.



\## Features

\- Male / Female themes

\- Adaptive workout program builder

\- Set-by-set workout tracker

\- Dashboard with charts

\- Breathing / decompression tools

\- Modular \& maintainable code
